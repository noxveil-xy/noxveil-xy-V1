## О проекте

**Noxveil-Xy** — персональный сайт-визитка и портфолио, созданный для представления моего профессионального профиля, технических навыков, опыта работы и практических проектов.

Основная задача проекта — собрать профессиональную информацию в одном месте и показать не только список технологий, но и практический подход к работе с инфраструктурой, системами и информационной безопасностью.

Основные направления:

* системное администрирование;
* информационная безопасность;
* Linux / Windows инфраструктура;
* сетевые технологии;
* DevOps-практики;
* автоматизация;
* разработка инструментов на Python и Bash;
* анализ сетевого трафика;
* мониторинг и обнаружение подозрительной активности.

## FS-BOX

**FS-BOX** — небольшое приложение для передачи файлов между устройствами и виртуальными машинами внутри локальной сети.

Проект создавался как практическое решение проблемы передачи файлов между виртуальными машинами без использования облачных хранилищ.

Основная технология:

* Python;
* TCP sockets;
* Client / Server architecture;
* Linux.

Проект также используется для практического изучения:

* сетевого взаимодействия;
* TCP-соединений;
* клиент-серверной архитектуры;
* работы с сокетами;
* обработки соединений;
* передачи данных.

## Network Scan Detector

Инструмент для обнаружения подозрительной активности, связанной с сетевым сканированием.

Основная идея проекта — обнаруживать признаки сетевого сканирования и формировать информацию, которая может использоваться для дальнейшего анализа.

Возможные компоненты:

* захват сетевого трафика;
* обнаружение сканирования;
* журналирование событий;
* анализ логов;
* ротация логов;
* работа в фоне;
* запуск через `systemd`.

# Security Operations Terminal

Одной из основных визуальных особенностей сайта является интерактивный терминал в нижней части страницы.

Он имитирует рабочую среду специалиста по информационной безопасности.

В терминале отображаются:

* команды;
* системные события;
* предупреждения;
* сетевые события;
* Security Alerts;
* Traffic;
* Threat Analysis;
* количество пакетов;
* количество событий;
* количество заблокированных событий;
* Uptime.

Примеры отображаемых команд:

```text
nmap -sS 192.168.1.20
tcpdump -i eth0
ss -tulpn
ip addr show
ip neigh show
iptables -L -n -v
systemctl status firewall
journalctl -u ssh
python3 network_monitor.py
```

Терминал является **визуальной симуляцией**.

Команды не выполняются на компьютере посетителя и не взаимодействуют с его системой.

# Подход к разработке

Проект разрабатывается поэтапно.

Каждая крупная часть сайта создаётся и дорабатывается отдельно:

```text
Архитектура
     ↓
Структура
     ↓
Визуальный стиль
     ↓
Responsive Design
     ↓
Интерактивные элементы
     ↓
Анимации
     ↓
Оптимизация
     ↓
Финальное портфолио
```

Такой подход позволяет отдельно контролировать структуру, внешний вид и поведение каждого компонента.
